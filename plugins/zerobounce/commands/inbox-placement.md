# Inbox placement

1. Call `list_inbox_placement_tests` on the `zerobounce` MCP server.
2. To inspect one test, call `get_inbox_placement_test`.
3. Creating a test spends credits. Confirm the from-address and test type, then call `create_inbox_placement_test`.
